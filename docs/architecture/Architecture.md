# CaseOS Architecture (pointer)

**This file is a pointer, not an architecture diagram.** The
seven-step ASCII sketch that used to live here described the V1
playground-only product and contradicts the current pipeline.

Authoritative sources for the current architecture:

- ADR-005 (Decision Intelligence) -- the 6-stage Agent pipeline
  (space -> decision_maker -> knowledge_retriever -> strategy
  -> object_selector -> explain).
- ADR-005a (Constitution cross-reference) -- the 4 principle
  bindings every agent must respect.
- ADR-006 (Project Fit Intelligence) -- the future Project
  Intelligence Layer (Project Fit, Budget, Safety, Commercial,
  Education, Psychology, Fengshui).
- ADR-006a -- records ADR-006 acceptance.
- ADR-007 (Constitution) and "CaseOS_Decision_Principles_V1.md" --
  the philosophy and implementation guide.
- "CaseOS_Product_Blueprint_V1.md" -- the user-journey spec.
- "backend/app/core/" -- the actual implementation.

Diagrams of the current pipeline live in the ADR files themselves
(see ADR-005 section 6, ADR-006 section 6).
