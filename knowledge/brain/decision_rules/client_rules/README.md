# Client Rules (CR)

- **Family:** CR
- **Stage:** 1 -- Client Understanding
- **Source:** `docs/architecture/ADR-010-decision-rules-framework.md`

Rules in this folder govern **how the Brain handles a
client "s input**. They apply before any project fit or
diagnosis. Most client rules are about asking the right
question, not producing the right answer.

V1 ships three rules:

- **CR-001** -- Do not design before project definition.
- **CR-002** -- Beginner client does not equal bad
  client.
- **CR-003** -- Clarify before creating.

See each rule "s file (e.g., `CR-001.md`) for full
content.
