# Theme Rules (TR)

- **Family:** TR
- **Stage:** 7 -- Theme Strategy
- **Source:** `docs/architecture/ADR-010-decision-rules-framework.md`

Rules in this folder govern **how a theme is selected,
bound to a strategy, and validated** against the five
gates (source legitimacy, story, extension, experience
path, composition) defined in
`knowledge/brain/theme_strategy/README.md`.

V1 ships no rules. Future TR rules will target theme
selection confidence, Gate 1-4 enforcement, and primary/
secondary composition.
