# PF-001 -- Design cannot replace operation capability

## 1. Rule ID

PF-001

## 2. Rule Name

Design cannot replace operation capability

## 3. Applicable Scenario

Project has good design conditions but poor operation
ability.

## 4. Observation Conditions

Project Fit Report shows:

- `space_condition` = adequate or above.
- `budget_band` = adequate or above.
- `operation_capability` = below adequate.
- `client_experience` = below adequate (or unknown).

## 5. Judgment

Design improvement alone cannot guarantee project
success.

The project will underperform regardless of design
quality.

## 6. Reasoning

Successful projects require:

- space + experience + operation.

If one of the three is missing, the other two cannot
compensate. This is the binding of Decision Principle
003 (Content serves purpose) and Principle 002 (Design
serves decisions).

## 7. Recommended Action

Provide **operation strategy consultation** alongside
design recommendation. Pair the client with an
operations lead if available. In the recommendation
report, add a Risk note: "Design is conditional on
operation capability being established".

## 8. Exceptions

The rule may not fire if the project is short-horizon
(single event, single weekend, single photo op). In
that case, operation is not in the project lifetime.

## 9. Example Cases

- A boutique hotel wants a signature rooftop, but its
  housekeeping team is already over-extended and cannot
  staff the rooftop. PF-001 fires -- a rooftop design
  without an operations plan is an underused asset.
- A kindergarten wants a sophisticated climbing forest
  but cannot guarantee daily adult-child ratios. PF-001
  fires; the recommendation must include staff
  staffing, not just the equipment.
