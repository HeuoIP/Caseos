# Project Fit Rules (PF)

- **Family:** PF
- **Stage:** 2 -- Project Fit
- **Source:** `docs/architecture/ADR-010-decision-rules-framework.md`

Rules in this folder govern **the match between the
project, the client, the budget, and the market**. They
fire after Client Understanding, before Space Cognition.

V1 ships one rule:

- **PF-001** -- Design cannot replace operation
  capability.

See `PF-001.md` for full content.
