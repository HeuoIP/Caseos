# Cognition Rules (CX)

- **Family:** CX
- **Stage:** 3 -- Space Cognition
- **Source:** `docs/architecture/ADR-010-decision-rules-framework.md`

Rules in this folder govern **the perception of a
space**. They fire when the Brain produces or consumes a
`SpaceCognition` record.

V1 ships no rules. Future CX rules will target the four
cognition axes (role, position, characteristics, state)
defined in `knowledge/brain/space_cognition/README.md`.
